# hkking

hkking 的作品发布页，这里只提供安装包下载，不含源码。

| 作品 | 说明 |
|---|---|
| GPT小龙娘安卓版 | 用悬浮窗住在手机屏幕上的龙娘桌宠：摸头、投喂、拖动甩飞、边缘偷看，互动时会用语音说台词，长按菜单里可以接 GPT 聊天 |

## 下载安装

到 **[Releases](https://github.com/hkk1121/hkking/releases/latest)** 下载最新的 `GPT小龙娘-vX.X.apk`，传到手机上安装即可（Android 11 及以上）。

首次打开按提示授予悬浮窗权限，再填好 API Key、API 地址和模型，点「保存并启动桌宠」。之后发布的新版本会在设置页提示，可以在应用里直接下载安装。详细的设置、互动玩法和常见问题见 **[使用说明](使用说明.md)**。
